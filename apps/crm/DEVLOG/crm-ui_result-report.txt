DEVIATIONS FROM THE HANDOVER (judgement calls)
  - CSS tokens: NOT verbatim. TrustWeb's light :root block defines --tint-teal/ok/warn/violet/blue/sand and --ok-ink/--warn-ink
    as var() of themselves (cyclic, so invalid and resolving to nothing in light mode). I could not recover the original values
    from git, so the CRM carries chosen light values (#E3F2EF, #DDF3EC, #FDE3DC, #EEE0FB, #E0F1F8, #F3ECDD, #0E6B49, #B4410F).
    The dark block is verbatim. I also copied the .tag-* chip rules and their dark overrides.
  - addInteraction(personId, kind, text, place?, at = Date.now()): one optional trailing parameter for the chosen date.
  - Follow-up due dates are stored as the END of the chosen local day, so "due today" sits under Upcoming ("today") and only
    turns overdue the next day. Interaction dates: today keeps the current time (same-day entries stay in order), another
    day is its local midnight.
  - Interaction events show the specific kind (Met/Call/Message/Event/Note) as label instead of the generic "Happened".
  - People rows: "Last: ..." counts only events up to now. A future follow-up no longer reads as recent activity. With nothing
    past it says "Upcoming" (something lies ahead) or "Nothing yet". Sort order still uses the library's lastAt.
  - Remove control on a contact point appears in the expanded view only (accidental-tap guard).
  - Follow-ups/timeline skip records whose person is not in the current record (after an import the seeded sample CRM
    still refers to p-lena etc.).
