RULES
  - snake_case filenames (.svelte included). Small functions. Explicit return types on every function.
  - Every visible string from S (strings.ts). Enums, not string literals, for fixed sets.
  - No network calls at all. No analytics. No external fonts (system font stack from TrustWeb's styles).
  - Accessibility: buttons are <button>, inputs have aria-label or a <label>, the tab bar is a <nav>.
  - Edge cases: a person with no channels/no lines/no events; an import that fails; storage blocked (state still
    works in memory: storage.ts returns false, the UI keeps going).
  - No em dashes in user-facing copy.
