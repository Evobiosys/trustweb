   Notes

     /apk matches the username pattern and would 302 to /who/apk unless the live file has an /apk handler above it. The

     No hand edit of the live file.
   - Install route: scripts/trustweb_domains.sh fetches the live file, applies the transform, runs `caddy validate` on
     questhub, installs and reloads, and restores the backup on failure.
