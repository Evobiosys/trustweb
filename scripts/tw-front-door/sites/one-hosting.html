Run it yourself

Build it and serve the files from any web server. The public copy of the code is on GitHub; it is paused and does not hold this app yet. Until it does, ask us for the current code at connect@evobiosys.org; the script below builds it.

git clone https://github.com/evobiosys/web-of-trust.git
cd web-of-trust
pnpm install --frozen-lockfile
cd apps/trustweb
TW_BASE=/ ../crm/node_modules/.bin/vite build
npx serve dist
