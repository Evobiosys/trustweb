Not a fit for everything

Where this is specifically useful, or necessary

Strongest first. Hover, tap, or tab to any of these for the reasoning and an example.

  • Only locally relevant Time-boxed, place-boxed information no platform is built to carry. Example
    "Cooked for eight people, four vegetarian portions left, pickup until 8pm."     Learn more →
  • Trust is the main issue Care work, pet care, house-sitting, childcare: who matters more than what. Example
    Finding someone to housesit through people who can actually vouch for them, not star ratings.     Learn more →
  • Not publicly possible Asks that would cause a problem the moment they're broadcast. Example
    Asking who has room to sublet while between leases, without your landlord finding out first.     Learn more →
  • Only certain people should see it An ask that's fine for some rings and wrong for others. Example
    A role filled through someone recommended, seen only by people close enough to vouch for a candidate.     Learn more →
  • Not worth listing publicly Tools, bikes, cargo bikes: below the value where a public listing's overhead pays off. Example
    Lending a cargo bike for a weekend move, never worth the hassle of a public rental listing.     Learn more →
  • Not currently worth posting Below the bar for a public offer, above the bar for a friend. Example
    We wouldn't fix up our apartment to make it an Airbnb, but if a friend of a friend needs a spot, we have one.     Learn more →
  • Honesty about flaws matters most For cars or tech, what you need is the flaw a seller has every incentive to hide. Example
    A friend telling you the real condition of a used car, something a listing never would.     Learn more →
  • Fair pricing When a market price would exploit the relationship rather than reflect it, for example a handicraft-worker's own skill. Example
    Paying a friend's actual rate for skilled work, not what a stranger platform would charge, and not what it would underpay them.     Learn more →
